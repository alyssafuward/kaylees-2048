# Kaylee's 2048

Galaxy Edition puzzle game — a 2048 clone.

Play it live: https://alyssafuward.github.io/kaylees-2048/

## Development

This project uses Vite, TypeScript, React, shadcn-ui, and Tailwind CSS.

```sh
npm i
npm run dev
```

## Deployment

Deploys to GitHub Pages from a `gh-pages` branch. To publish the current code:

```sh
npm run deploy
```

This builds the app and pushes `dist/` to the `gh-pages` branch, which GitHub
Pages serves from.
