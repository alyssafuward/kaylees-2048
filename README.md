# Kaylee's 2048

Galaxy Edition puzzle game — a 2048 clone.

Play it live: https://alyssafuward.github.io/kaylees-2048/

## Development

This project uses Vite, TypeScript, React, shadcn-ui, and Tailwind CSS.

```sh
npm i
npm run dev
```

## Deployment

Pushes to `main` are built and deployed to GitHub Pages automatically via the
workflow in `.github/workflows/deploy.yml`.
